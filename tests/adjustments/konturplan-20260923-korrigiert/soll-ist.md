# Soll-Ist-Prüfung des IroGen-Konturplans

Keine Nutzerabnahme; nominale Farbabweichungen sind kein Prüfkriterium.

- Rechtecke abnehmend senkrecht - SOLL messbar ohne Perspektivhinweis: **erfüllt**. 3 von 3 Feldern gemessen, größte Abweichung 0,00 ΔE00
- Rechtecke zunehmend senkrecht - SOLL messbar ohne Perspektivhinweis: **erfüllt**. 3 von 3 Feldern gemessen, größte Abweichung 0,00 ΔE00
- Kontrolle senkrecht - SOLL alle drei Felder messbar: **erfüllt**. 3 von 3 Feldern gemessen, größte Abweichung 0,00 ΔE00
- Verjuengung senkrecht - SOLL gesperrt mit Frontalhinweis: **erfüllt**. Kein Farbfeld gemessen (Status ungeeignete Geometrie)
- Verjuengung dunkel verrauscht senkrecht - SOLL gesperrt mit Frontalhinweis: **erfüllt**. Kein Farbfeld gemessen (Status ungeeignete Geometrie)
- Rechtecke abnehmend waagerecht - SOLL messbar ohne Perspektivhinweis: **erfüllt**. 3 von 3 Feldern gemessen, größte Abweichung 0,00 ΔE00
- Rechtecke zunehmend waagerecht - SOLL messbar ohne Perspektivhinweis: **erfüllt**. 3 von 3 Feldern gemessen, größte Abweichung 0,00 ΔE00
- Kontrolle waagerecht - SOLL alle drei Felder messbar: **erfüllt**. 3 von 3 Feldern gemessen, größte Abweichung 0,00 ΔE00
- Verjuengung waagerecht - SOLL gesperrt mit Frontalhinweis: **erfüllt**. Kein Farbfeld gemessen (Status ungeeignete Geometrie)
- Verjuengung dunkel verrauscht waagerecht - SOLL gesperrt mit Frontalhinweis: **erfüllt**. Kein Farbfeld gemessen (Status ungeeignete Geometrie)
